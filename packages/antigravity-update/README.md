# antigravity-update

Install or update Antigravity IDE, wherever it lives.

    antigravity-update --check      # is there a newer build?
    antigravity-update              # install it
    antigravity-update --desktop    # just fix the launcher and icon

The install directory is discovered, not assumed. If the IDE is not installed
at all, you are asked whether to install it and where.

See `man 1 antigravity-update`.
